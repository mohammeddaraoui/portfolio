# Portfolio — Daraoui Mohammed

Portfolio personnel : marketing, communication, création de contenu et animation pédagogique.

## Utilisation
Ouvrir `index.html` dans un navigateur. Le CSS et le JavaScript sont intégrés dans ce fichier. La photo se trouve dans `assets/portrait.webp`.

## GitHub Pages
Dans Settings → Pages, sélectionner Deploy from a branch, puis main et /(root).
